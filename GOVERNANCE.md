# Governance (prototype)

This is a maintainer-led open-source project. The maintainer group is whoever
has write/merge permission in the Git hosting organization. No governmental
mandate or legal authority is implied.

- Public proposals and changes are made through issues and pull requests.
- Maintainers review code, legal-source references, examples and regression tests.
- A release is a tagged software version. Its legal meaning is limited to what
  the applicable external law provides; a Git tag does not enact legislation.
- Reports of errors are corrected through subsequent commits and releases.
- Forks may modify and redistribute the code under LICENSE.

When the repository is hosted, protect the default branch and require at least
one approving maintainer review plus passing CI. Those hosting settings cannot
be activated by files in this starter archive alone.
